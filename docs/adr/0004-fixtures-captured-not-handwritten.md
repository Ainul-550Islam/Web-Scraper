# Contract fixtures are captured from a running engine

Status: **Accepted**

## Context & decision

`web/src/test/fixtures/*.json` were generated by hitting the real `harvest serve` endpoints — never typed by hand — so every assertion doubles as a drift detector for the wire format. Regenerating them is the only sanctioned way to change expectations; if a fixture and `web/src/lib/types.ts` disagree, tsc fails, which is the intended tripwire.
